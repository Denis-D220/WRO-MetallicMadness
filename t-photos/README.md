# Team Photos

This folder contains team photos for the **MetallicMadness / ARBIBOT** WRO Future Engineers self-driving car project.

The purpose of this folder is to document the team behind the robot and provide the required visual identity material for the project repository and WRO documentation.

## Folder contents

| File | Description |
|---|---|
| `team.png` | Formal team photo for the MetallicMadness / ARBIBOT project. This image should be used as the main official team photo in the repository and Engineering Journal. |
| `team-fun.png` | Informal/fun team photo. This image shows the team personality and can be used in the Engineering Journal or project presentation as a secondary team image. |

## Photo purpose

The photos in this folder help document:

- the team participating in the WRO Future Engineers project,
- the people responsible for designing, building, testing, and documenting ARBIBOT,
- the formal team identity,
- and the collaborative spirit of the project.

## Recommended usage

The formal photo should be used as the primary team image:

```markdown
![MetallicMadness team photo](t-photos/team.png)
```

The fun photo can be used as a secondary image:

```markdown
![MetallicMadness fun team photo](t-photos/team-fun.png)
```

From a file inside `docs/`, use:

```markdown
![MetallicMadness team photo](../t-photos/team.png)
```

From `engineering-journal/engineering-journal.md`, use:

```markdown
![MetallicMadness team photo](../t-photos/team.png)
```

## Recommended documentation links

These images can be referenced from:

```text
README.md
engineering-journal/engineering-journal.md
docs/05-systems-thinking-decisions.md
```

## Naming convention

Use lowercase filenames with hyphens:

```text
team.png
team-fun.png
```

If more photos are added later, use clear names:

```text
team-working-on-robot.png
team-with-robot.png
team-testing-track.png
team-presentation.png
```

## Update policy

When team photos change:

1. Add the new image to this folder.
2. Update this README.
3. Update any links in the root `README.md` or Engineering Journal.
4. Keep `team.png` as the main formal team photo when possible.
